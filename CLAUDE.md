# RemoteTubeAmplifaier

Контроллер лампового усилителя мощности (УМ): перестройка конденсаторов П-контура и коммутация реле.

## Текущее направление

УМ переводится на ESP32 с веб-мордой для контроля и управления.

- Плата: LilyGO T-Halow (ESP32).
- Код прошивки: `esp32-backend/esp32-backend.ino` (Arduino, ядро esp32 3.x).
- Старая реализация на Python (`py_server/`, `py_client/`, `common/`, Mechaduino + Raspberry Pi) — предыдущее поколение, в рамках новых задач не развивается.

## Задача 1 — веб-морда с таблицей частот

Постановка: сделать веб-морду, на которой отображается таблица для выбора частот. При выборе частоты меняется положение сервопривода. Пока всё.

Что сделано:

- Веб-страница встроена в прошивку и отдаётся с самой ESP32 (`WebServer`, порт 80).
- Таблица: строка на диапазон, в ней кнопки частот с шагом 25 кГц; выбранная частота подсвечивается.
- HTTP API:
  - `GET /api/table` — диапазоны и точки `[частота кГц, угол]`;
  - `GET /api/state` — текущие частота и угол;
  - `POST /api/select?freq=<кГц>` — выбрать частоту и повернуть серву.
- Серва управляется через LEDC (50 Гц, 14 бит), без сторонних библиотек.
- Wi-Fi: если `STA_SSID` пустой — своя точка доступа `TubeAmp` (192.168.4.1), иначе подключение к указанной сети.

Что не сделано / заглушки:

- Углы для частот — заглушка: линейная интерполяция по диапазону из таблицы `BANDS`. Реальной калибровки нет.
- `SERVO_PIN` выставлен условно, под распиновку T-Halow не сверялся.
- Выбранная частота не сохраняется между перезагрузками.
- Прошивка не собиралась и не проверялась на железе.
